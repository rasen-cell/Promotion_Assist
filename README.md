# Promotion Assist（仮）

小説・漫画の Web／SNS プロモーションを支援・自動化する個人開発ツールの企画リポジトリです。
現時点ではリサーチ結果・ニッチ選定・仕様書を収めています（実装は未着手）。

## 結論（要約）

- **選んだニッチ**：「作品を更新したら、SNS ごとに最適化した告知（文・画像・リンク配置・タグ）が自動で整い、無料 API の SNS（Bluesky / Misskey / Threads）には自動投稿、X には安全なワンクリック投稿」を提供する **Web 小説・Web 漫画作家専用の告知アシスタント**。
- **なぜここか**：
  - 汎用の SNS 予約投稿は無料ツール（MultiPost 等）や Buffer が既に占めており、機能で戦えない。
  - 2026 年の X API は従量課金（投稿 $0.015、URL 付き $0.20 と報告）で、無料枠前提の個人ツールは成立しない。一方 Bluesky / Misskey / Threads の API は無料で、創作クラスタの移住先として伸びている。
  - 小説家になろうには公式 API があり、規約に沿った更新検知・効果測定ができる。カクヨム等はスクレイピング禁止のため、作者本人の共有操作で URL を受け取る設計にする。
  - 作家の痛みは「多重投稿の手間」「毎回同じ文面」「効果が見えない」「宣伝疲れ」に集中しており、既存ツールはどれも点在する単機能（縦書き画像化、画像分割、お品書き）に留まる。
- **MVP の範囲**：なろう作品登録（ncode）、更新検知、テンプレート＋言い回しローテーション、SNS 別変換、縦書き冒頭カード生成（ブラウザ内）、Bluesky / Misskey 自動投稿、X Web Intent、1 日 1 回ガード、予約投稿。
- **拡張**：Threads（審査後）、効果測定（なろう API 日次スナップショット）、漫画モード（4 枚分割・1p 目訴求・縦長結合）、同人イベント告知パック、Kindle リンク、AI 文章補助（既定オフ）。
- **収益**：Free（作品 1 件）／Pro 月 500 円前後。X 自動投稿は利用者自身の API クレジット（BYOK）。

## 現在の状態：v0 プロトタイプ（動作する）

リスク評価（`docs/04_risk_assessment.md`）の結果、**外部 API に依存しない静的 Web アプリ** にスコープを絞った v0 を `prototype/` に実装しました（`docs/05_v0_scope.md`）。

- 作品と今回の更新を入力すると、X / Bluesky / Threads / Misskey / Mastodon 向けの告知文（文字数・リンク配置・タグ・言い回しローテーション済み）と縦書きの宣伝画像が生成されます。
- 投稿は各 SNS の公式共有画面を 1 タップで開くだけです。自動投稿・トークン保管・作品サイトへの自動アクセスは行いません。
- なろう小説 API による作品情報の自動入力は任意機能で、失敗時は手入力に戻ります。
- データはブラウザの localStorage にのみ保存され、JSON で書き出し・読み込みできます。

```
npm test      # 単体テスト（node:test）
npm run e2e   # ブラウザ通しテスト（Playwright + Chromium）
npm run dev   # http://localhost:8080 で起動
```

既知の制限：縦書きの禁則処理（行頭の句読点）は未実装。共有インテントでは画像を添付できないため、画像は保存・コピーして手で貼る。なろう API の疎通は開発環境の制約で未検証（単体テストは URL 組み立てと応答の正規化まで）。
